# ARKHÉON API v1

All responses use JSON envelopes:

```json
{
  "ok": true,
  "data": {},
  "meta": { "requestId": "uuid" }
}
```

Errors use a stable `error.code` and a safe public message. Internal exceptions, credentials, and SQL details are never returned.

## Public routes

| Method | Route | Purpose |
| --- | --- | --- |
| `GET` | `/api/v1/health` | Service liveness without secret details |
| `POST` | `/api/v1/auth/telegram` | Validate raw Telegram `initData` and create an opaque session |
| `GET` | `/api/v1/airdrops` | Published FREE-FIRST feed with `locale`, `cost`, and `limit` filters |
| `GET` | `/api/v1/airdrops/:slug` | Published opportunity and published tutorial |
| `GET` | `/api/v1/ranking?scope=saudi` | Real Saudi-first points ranking; never seeded with fake entries |

## Authenticated routes

Authenticated routes require `Authorization: Bearer <opaque-session-token>`.

| Method | Route | Purpose |
| --- | --- | --- |
| `GET` | `/api/v1/me` | Safe user profile |
| `GET` | `/api/v1/me/saved` | Saved published opportunities |
| `PUT` | `/api/v1/me/saved/:airdropId` | Save a published opportunity idempotently |
| `DELETE` | `/api/v1/me/saved/:airdropId` | Remove a saved opportunity idempotently |
| `GET` | `/api/v1/me/points` | Current ledger total and non-financial classification |
| `GET` | `/api/v1/me/referral` | Referral code, verified counts, and optional Telegram deep link |
| `POST` | `/api/v1/me/activity` | Record a bounded, validated product activity event |

## Publication boundary

The feed only returns `published`, `ending_soon`, or `claim_live` records. Draft, rejected, watching, and under-review records never leave the server through public routes. `startUrl` is derived only from the verified referral URL or official URL stored on an eligible public record.

ARKHÉON Points are gamification and reputation records. The API explicitly marks them as having no financial value.
